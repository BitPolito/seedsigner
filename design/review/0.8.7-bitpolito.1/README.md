# BitPolito 0.8.7 visual review

The checked-in review is English-only, as approved for this iteration. Open the
[English review index](en/README.md) for the six-sheet set covering all 139
generated screens.

The source screenshots are generated by:

```bash
python scripts/build-review-sheets.py \
  --input artifacts/<quality-gate>/screenshots.<run>/en
```

The individual screenshots remain CI artefacts; the compact sheets and
`full/manifest.json` are the review material kept in the repository.
